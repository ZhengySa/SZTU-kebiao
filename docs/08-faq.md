# 08 · 常见问题（FAQ）

## 安装与运行

**Q：装不上 / 提示「解析包时出现问题」**
A：`app-debug.apk` 是 debug 包，需要 Android 8.0（API 26）以上。用 `adb install -r` 或文件管理器直接点开安装。
如果之前装过改过包名的版本，先卸载再装。

**Q：第一次打开是空的，只有「今日无课」**
A：正常。首次启动会自动建 12 节默认时间和一个默认学期，但没有任何课程。
去「设置 → 教务系统同步」登录一次，课表就全进来了；也可以手动加课或用 ICS/CSV 导入。

## 教务系统同步

**Q：为什么点了同步，提示「验证码错误」/ 验证码看不清？**
A：验证码是学校服务器实时生成的，5 分钟内有效，而且和当前会话绑定。
看不清就点验证码图片换一张；连续错两次建议返回再进一次，让会话重新建立。

**Q：提示「登录状态已失效」**
A：学校会话有过期时间。回到登录页重新输一次验证码即可，学号密码会帮你填好。

**Q：导入后第 11 节时间不对**
A：同步时会把学校的 15 节作息一起导进来，正常情况下不会错。如果显示不对，
去「设置 → 节次时间」看一眼是不是被手动改过——同步只在导入那一刻覆盖节次表。

**Q：会不会把我课表传到你们服务器？**
A：没有"我们服务器"。整个 App 没有任何自建后端，请求只发往 `jwxt.sztu.edu.cn` 和
`auth.sztu.edu.cn`，域名白名单写在代码里，其它地址的请求会直接抛异常。

**Q：密码存在哪？**
A：Android Keystore AES/GCM 加密后存本地，密钥在手机的安全芯片里，App 自己也读不到明文。
登录页可以不勾「记住密码」，那样密码只用一次。

**Q：换学校能用吗？**
A：不能直接用。`SztuConfig` 里的域名/接口、`ZfKbParser` 和 `ZfCalendarParser` 的解析规则都是按本校页面写的。
换学校等于重写这三个文件，其余部分（周次、冲突检测、界面）不用动。

**Q：学校页面改版了，同步还会好吗？**
A：解析器有真实页面夹具做回归测试（`app/src/test/resources/fixtures/`）。
页面改版导致少解析课程时，`ZfKbParserTest` 会先红，而不是让你拿到一张缺课的课表。

## 课表显示

**Q：明明加了课，周课表上却不显示**
A：按顺序查三个地方：
1. 设置 → 学期：开学日期对不对？当前周是不是被手动改到了这门课不上课的周？
2. 这门课的时段选的是「单周 / 双周 / 指定周次」，当前周可能正好不上；
3. 周课表顶部的周次滑块是不是停在了别的周。

**Q：改了第 3 节的时间，之前的课会不会乱**
A：不会。课时只存「第几节」，具体几点是从节次表现算的，改时间等于全 App 同步改，历史课程不会错位。

**Q：一门课一周上两次（周一 1-2 节、周三 5-6 节）**
A：在课程编辑页点「+ 添加时段」，一门课可以有任意多个时段，颜色和课程名共用一份。

**Q：跨节的课（1-4 节连上）显示成了 4 块**
A：不会。周课表里跨节课程是一整块，高度按节数算。如果看到被切开，说明你建成了 4 个独立时段，改成 1 个「1-4 节」的时段即可。

## 导入

**Q：导入后课程位置不对（比如 8:00 的课跑到第 3 节）**
A：导入是按「时间最接近」映射到节次的。如果学校作息和你设置里的节次表差很多，
先去「设置 → 节次时间」把作息改对，再重新导入。

**Q：ICS 导入后一门课都没有，只有一堆提示**
A：常见三种原因：
- 文件里是全天事件（只有日期没有时间），无法映射到节次，会被跳过；
- 事件用了 `FREQ=DAILY` 之类非周重复，当前只支持 `FREQ=WEEKLY`；
- 课程日期不在本学期范围内（开学日期设错了最常见）。
预览页的「提示」区会逐条写明被跳过的原因。

**Q：CSV 用 Excel 存出来是乱码**
A：App 会先按 UTF-8 读，发现乱码字符再自动按 GBK 读，一般不会乱。
如果还是乱，在 Excel 里「另存为 → CSV UTF-8」再试。

**Q：导入时选「合并」和「覆盖」有什么区别**
A：合并 = 保留现有课程，同名课程跳过（同名视为同一门课，重复导入不会变两份）；
覆盖 = 先清空本学期所有课程，再写入这批。覆盖不可撤销，建议先导出备份。

## 桌面小组件

**Q：找不到小组件**
A：长按桌面空白处 → 小部件 → 找到「课表」。也可以在 App 里「设置 → 桌面小组件 → 直接添加到桌面」。

**Q：小组件一直显示旧数据**
A：正常刷新路径有三条：改课程/改节次/切周 → 立刻刷新；每天 00:05 WorkManager 刷新；开机/改时区/跨天广播刷新。
如果都不生效，检查是不是把 App 的「后台运行」权限关了，或者在桌面把小部件删掉重新加一次。

**Q：小组件显示「还有 N 节」**
A：桌面空间不够时的折叠显示。把小组件往下拉高就能看到全部（最多 6 条）。

## 提醒

**Q：到点没有提醒**
A：依次检查：
1. 设置 → 课前提醒：开关是否打开，提前分钟数是多少；
2. 系统通知权限：设置 → 应用 → 课表 → 通知；
3. 系统「闹钟和提醒」权限（Android 12+）：不给也能用，但提醒可能晚几分钟；
4. 手机厂商的后台管理（小米/华为/OPPO 等）可能杀掉闹钟，把课表 App 加入「允许后台运行」白名单。

**Q：提醒时间不准，晚了十几分钟**
A：说明系统没授予「闹钟和提醒」权限，此时降级为 ±10 分钟窗口（避免完全收不到）。去系统设置里允许即可精确到分钟。

## 数据与备份

**Q：换手机怎么迁移**
A：旧手机「设置 → 备份与恢复 → 导出备份文件」，把 JSON 发到新手机，新手机选「从备份文件恢复」。恢复是整体替换。

**Q：卸载 App 后数据还在吗**
A：不在。数据库随应用一起删除。卸载前务必导出备份。

**Q：会上传我的课表吗**
A：不会。App 没有申请 INTERNET 权限，物理上没有联网能力。备份文件只存在你选的位置。

## 开发相关

**Q：编译报 `The 'org.jetbrains.kotlin.android' plugin is no longer required`**
A：AGP 9 起 Kotlin 编译内置，删掉 `app/build.gradle.kts` 里的 `kotlin.android` 插件别名。

**Q：编译报 `拒绝访问 ... .lock`**
A：Gradle 的锁文件被上次中断的编译卡住了，删掉
`C:\Users\ZhengY\.gradle\caches\9.8.2\transforms\.internal\locks` 后重试。详见 `docs/07-build-environment.md`。

**Q：能改成支持研究生课表 / 一天 14 节 / 三学期制吗**
A：节次数可以在代码里扩（默认 12 节，`DefaultData.defaultSlots()`），学期已经支持多学期并存，
时长规则只要 `WeekMask` 的 60 周上限够用就不用改。改表结构时必须写 Room Migration，**不要用 `fallbackToDestructiveMigration()`**。
