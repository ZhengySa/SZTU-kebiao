# 17 · 今日页一天一页：把「一周 7 页」改成整学期连成一条

> 关联需求：「第九周划到周日再往后划就到第十周啊，为什么又卡住了」

## 一、先说结论：问题不在周课表

上一轮（[docs/16](16-luck-box-swipe-and-privacy.md)）把周课表的翻周门槛从 0.5 降到 0.12，
那次改动是有效的 —— 在模拟器上从第 9 周连续轻扫，能一路到 10、11、12 周。

但用户说的「划到周日再往后划」根本不发生在周课表上：周课表把 7 天全部塞在一屏，
**没有"划到周日"这个动作**。真正能一天一天划的，是**今日页**。

今日页的日滑动是 `HorizontalPager`，页数写死成 7：

```kotlin
val pagerState = rememberPagerState(initialPage = initialPage) { 7 }
```

于是第 9 周周日 = 第 7 页 = Pager 的最后一页。再往后划，Pager 没有下一页可去，
**手势直接失效**。用户看到的"卡住"完全是这个 7 造成的，跟翻页门槛毫无关系。

模拟器复现（改之前）：今日页连划 8 次，停在第 9 周 · 周日，之后怎么划都不动。

## 二、修法：页码 = 整学期的第几天

日历本来就是连续的。周日往前一步就该是下周一，中间不该有"换一屏"的断点。
所以把页数从 7 改成 `总周数 × 7`，页码直接当"学期的第几天"用：

```
page       ∈ [0, totalWeeks * 7)
week       = page / 7 + 1
dayOfWeek  = page % 7 + 1
date       = 开学日所在周的周一 + (week - 1) * 7 + (dayOfWeek - 1)
```

第 9 周周日是 `(9-1)*7 + 6 = 62` 页，下一页 `63` 自然就是第 10 周周一 —— 不需要任何
"到边界就换周"的特殊逻辑，因为压根没有边界。

`TodayUiState` 只保留这些纯函数（`weekOfPage / dayOfPage / dateOfPage / coursesOfPage /
todayPage / totalPages`），`TodayPageMappingTest` 六条用例把它们钉住，其中一条
就是「sunday plus one page is next monday」。

## 三、数据：一次算全学期

原来 ViewModel 是 `GetWeekCoursesUseCase(semester, week)`，只查当前这一周。
现在页码能跨到任意周，翻页时再异步查库会让新页先空一下。
改成 `GetAllWeekCoursesUseCase` —— 一次算完 20 周（几百次过滤，比一次翻页卡顿便宜得多），
翻页只是读内存里的一张 Map。

**页码不回流到 ViewModel。** `uiState` 只负责"今天是第几周 + 整学期的课"，
当前翻到第几天完全由 Pager 持有。否则每划一天就要重建一次数据链，手感会一顿一顿的。
页头显示的第 N 周也从 Pager 的当前页派生，全页只有 Pager 一个"当前是第几天"的来源。

## 四、顺带处理掉的几件事

**首帧定位**：数据没到之前 `state` 是默认值，初始页只能按默认值算。所以数据一到，
补一次 `scrollToPage(todayPage)`。用 `rememberSaveable` 记住"已经定位过"，
只在第一次做 —— 否则从课程详情返回、切 tab 回来都会把用户正在看的周拽回今天
（实测返回后仍停在第 9 周周三）。

**翻页门槛**沿用周课表那套：`snapPositionalThreshold = 0.12f`、`PagerSnapDistance.atMost(1)`、
`beyondViewportPageCount = 1`。轻扫一天就走，甩再快也不会跳过好几天。

**边界**：`weekOfPage` 夹在 `1..totalWeeks`，`todayPage` 夹在 `0..totalPages-1`。
第 20 周周日再往后划不会崩（尽头就是尽头，但那是真尽头，日历到这儿没了）。

**箭头**改成整周跳：`±7` 页，保持星期几不变。跨周时那一下比普通翻页更"重"。

## 五、验收（模拟器 Medium_Phone_API_37.0）

| 动作 | 结果 |
| --- | --- |
| 第 9 周周三起连划 4 次 | 周日 11/1，页头「第 9 周 / 共 20 周」 |
| 周日再划 1 次 | **第 10 周 周一 11/2，3 节课**，「回到本周」出现 |
| 反向划 1 次 | 回到第 9 周周日 11/1 |
| 连续划 9 次 | 11/10 周二（一天不差） |
| 点课程卡 | 进详情；返回后仍停在第 9 周周三 |
| 箭头「下一周」×2 | 第 11 周 周三 |
| 跳到第 20 周再狂划 4 次 | 停在第 20 周，进程不退出 |

单元测试 74 → **80 条全过**。
