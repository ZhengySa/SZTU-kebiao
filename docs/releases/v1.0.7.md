## 这版加了图书馆藏查询

### 百宝箱里多了一格

设置 → **百宝箱 → 图书馆藏查询**。用的就是学校图书馆那套馆藏检索
（`agentdockingopac.featurelib.libsou.com`，schoolId 32550）。

- 关键词 / 题名 / 作者 / 索书号都能搜，结果直接给**索书号、ISBN、出版社**，
  点进去看**馆藏地、条码号、在不在馆**——比如「C-2图书馆四楼 · 在馆」。
- 不用跳浏览器，App 里就能翻。系统返回先退网页的上一层（详情 → 结果 → 首页），
  退到头才回设置；页面左上角的 ← 是一步回设置。
- 顶栏两个按钮：**刷新**、**在浏览器打开**。借书、登录"我的图书馆"这类要 Cookie 的事，甩给浏览器更稳。
- 加载失败不会白屏：给一个「重新加载」，下面还有「用浏览器打开」兜底。

### 为什么是网页而不是原生列表

公文通能做成原生列表，是因为它就是个服务端渲染的站群，正文可以抓。
馆藏检索不一样：搜索条件、分页、馆藏状态、续借全在对方的服务里，
抓接口等于跟着人家改版一起崩。这种"对方才是唯一真相"的页面，套 WebView 反而活得久。

这一页也按 WebView 该有的规矩来：只跑 https、不许降级混载、file / content 访问全关掉、
离开页面就 destroy，不放任它常驻内存。

## 升级

自签名包，直接覆盖安装。这版只加了页面和一条路由，没动数据库、没动设置存储。

首页和底部栏都能照常用——图书馆在百宝箱里，不占底部栏位置。
