## 这版新增：考试安排（只查期末）

设置 → 学业 → **考试安排**。数据来自教务系统「学生考试查询」，和课表、成绩走同一个会话，不用再登一次。

- 按日期分组，一场一张卡：开始-结束时间、教室、座位号、闭卷/开卷
- 顶部显示共几场、最近一场还有几天
- 只留期末：教务端能按「期末」筛就先筛一遍，回来再按考试名称过滤，补考/缓考不混进来
- 安排还没发布时明确写「还没出来」，不会给你一个空列表让你怀疑是不是查错了

## 关于解析

教务各校部署的字段名不一样（`xqlb` / `xqlbmc` / 数字 id 都见过），所以没有写死参数：
**页面上的查询表单原样提交**，只把学期换成你当前这学期、顺便勾上「期末」。
结果表按表头文字认列（课程 / 时间 / 地点 / 座位 / 形式），列的顺序变了也照样读。

## 隐私

考场和座位属于敏感信息，所以考试安排**不缓存**：每次打开现取，只留在内存里，
不进数据库、不进 JSON 备份、也不进桌面小组件。成绩仍然缓存（它不会变），两者分开处理。
隐私说明页里补了这一段。
