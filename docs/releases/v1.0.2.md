## 这版改了什么

### 教室跟着每一节课走

以前一门课的所有教室被拼成一行存着，像 `C-5-215 / D-3-321` 这样，看不出哪个时间在哪个教室。
「传感器」这种一周三个时间、三个不同教室的课特别难受。

现在地点存在**每个时段**上，教务导入、CSV、ICS 三条路径都改了：

- 周课表里同一门课的不同节次，各自显示自己的教室
- 课程详情的时段列表，时间和教室分两行显示，教室加粗
- 导入预览每条时段后面标 `@教室`，导进来之前就能核对
- 只有全学期都在同一个教室时，课程级地点才填值；否则留空（假答案不如没有）

升级时数据库会做一次迁移，把以前拼接出来的旧地点串清掉，然后重新同步一次课表就能拿到正确的地点。

### 桌面图标可以换了

设置里新增「桌面图标」，内置 6 款极简图标：

| 图标 | 样子 |
| --- | --- |
| 格 | 课表格子 |
| 钟 | 圆环 + 两根指针 |
| 条 | 三条横杠 |
| 书 | 书脊 |
| 点 | 圆环 + 一个圆点 |
| 经典 | 原来那款 |

选完即时生效，桌面上的图标会跟着变。也可以自己选一张图作为图标——系统不允许应用直接换自己的图标，
所以这一项是往桌面放一个快捷方式，用的是你选的那张图（自动裁成圆形）。

### 自定义背景终于看得清了

原来的背景只是把图模糊一下铺在后面，白字糊在上面基本没法看。现在渲染前做了四层处理：

1. **模糊**（Android 12+ 用 RenderEffect，低版本退回放大绘制）
2. **降饱和**，把花花绿绿的图压成灰调
3. **主题色罩**，往上盖一层跟当前主题同色的半透明
4. **上下渐变 scrim**，顶栏和底栏再压暗一些

同时有背景时，玻璃卡片会自动变得更实（不再靠透明度硬糊）。

强度给了三档：**淡 / 中 / 浓**，默认「中」。觉得还是花就调到浓，觉得背景被盖死了就调淡。

### 顺手修的两个问题

- **Excel 导出的 CSV 认不出表头**：文件开头带 BOM，第一列表头名字对不上，整份被拒。现在会先剥掉 BOM。
- **重复导入同一份课表会报时间冲突**：同名课程跟自己比了一遍，现在跳过。

## 安装

1. 点下面 **Assets** 里的 `ClassFlow-v1.0.2.apk` 下载到手机
2. 手机上点开安装，允许「未知来源」
3. 直接覆盖安装即可，课表和设置不会丢

**系统要求**：Android 8.0（API 26）及以上
