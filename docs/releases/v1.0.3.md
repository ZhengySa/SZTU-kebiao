## 这版修的是上一版留下的事

1.0.2 把「教室跟着每个时段走」做对了，但有个后果没处理：**已经导进 App 的课，教室是空的**。

原因：1.0.2 之前，一门课的教室是拼成一串存在**课程级**的（`C-5-215 / D-3-321`），
时段本身没有地点。1.0.2 判断那串是错的就清掉了 —— 判断没错，但清完之后没有替代来源，
于是这些课全变成「地点待填」，你得一个个手输。这是我上一版没做完的部分。

### 现在它会自己补

打开 App 那一刻，如果发现有「导入进来、但时段没地点」的课，就用你登录教务时留下的会话
重新读一遍课表，把每个时段的教室按时间逐条填回去。补完弹一句「已从教务补全 N 个时段的教室」。

顺序是这样的：

- 每个时段按 **星期 + 起止节次** 对齐，不是按列表顺序猜
- 只填空位：你自己手填过的地点不会被覆盖（可能是你特意写的备注）
- 不会删你自己加的时段
- 全学期同一个教室的课，课程级地点也一并补上，列表页不用逐条翻

如果教务那边登录过期了，会提示你「去『教务同步』重登一次」——验证码只能人看，这一步没法替你点。

### 「只补充」这个模式原来是个摆设

以前选「只补充」再同步，同名课程会被**整门跳过**，所以教室永远补不上。
现在它真的会更新：补教师、补时段教室、插入新排出来的时段，已有的颜色、备注、周次都不动。
同步完成后的提示也会写清楚「更新了几门、补了几个时段的教室」。

### 手输也少填几格

- 课程编辑页：填了「默认地点」后有一键「所有时段都用这个地点」
- 课程详情页：地点空着的地方现在可以点，直接进编辑

## 安装

1. 点下面 **Assets** 里的 `ClassFlow-v1.0.3.apk` 下载到手机
2. 手机上点开安装，允许「未知来源」
3. 直接覆盖安装，课表和设置都不会丢。装完打开 App，教室会自己补上

**系统要求**：Android 8.0（API 26）及以上

## 注意

- 自签名包，签名和之前几版一致，可以直接覆盖升级。
- 手动添加的课不会被自动改（本来就可能不写地点），要补就点地点那一行。
