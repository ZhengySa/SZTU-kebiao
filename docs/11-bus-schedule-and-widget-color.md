# 11 · 校园巴士时刻（直峰专线 655）

## 功能

底部导航第 4 个 Tab「巴士」，进入后可查深圳技术大学校园公交（直峰专线 655）的时刻表：

- **方向切换**：北区方向 / 南区方向。
- **站点切换**：发车时刻 / 地铁站到站 / 教学楼到站 / 终点站到站（北区 +8.5min、南区 +8.5min、地铁站北区 +1min 南区 +6min、教学楼 +4min）。
- **工作日 / 休息日切换**：工作日表为 2026-10 录入的小程序截图数据；休息日数据暂未收录，页面明确提示"以小程序为准"，不编造数据。
- **下一班高亮**：顶部卡片显示下一班时刻、等待分钟数、全天班次总数；时刻矩阵里已过班次变灰、下一班用强调色高亮，每 30 秒自动刷新。

## 数据与代码

- 数据硬编码在 `domain/model/BusData.kt`，紧凑写法 `"07 00 10 20 30"` = 07 点的 00/10/20/30 分，与截图逐格核对。
- 页面在 `ui/screen/bus/BusScreen.kt`，纯静态数据 + `LocalTime`，不依赖 Room / 教务系统，不需要 ViewModel。
- `BusData.nextDeparture(direction, stop, now)` 负责"下一班"计算；`BusData.isWorkday(dayOfWeek)` 按周一~五判工作日。

## 测试

`BusDataTest`（9 条）：四方向×四站点全表完整性、分钟值合法性、两张表抽检与截图逐格一致、下一班边界（整点命中 / 过点跳下一班 / 末班后 null）、休息日空表、工作日判断、班次总数一致性。

## 更新时刻表

学校改点后只需改 `BusData.kt` 里对应表的字符串，测试里的抽检行同步更新即可。
