# 翻周手感、百宝箱、隐私说明重写

## 一、为什么"划到周日再往后划"会卡住

不是手势冲突，也不是状态同步在打架 —— 是**翻页门槛太高**。

`HorizontalPager` 默认的 `PagerDefaults.flingBehavior` 把
`snapPositionalThreshold` 定在 **0.5**：手指要拖过屏幕宽度的一半，抬手才认这一页。
360dp 宽的屏就是 180dp，日常那种"轻轻划一下"根本到不了，松手就弹回原页 ——
看起来就是"划不动"。

真机上用 adb 复现（1080px 宽）：

| 手势 | 改之前 | 改之后 |
|---|---|---|
| 慢速短划 200px / 700ms | 停在原周 | 翻到下一周 |
| 慢速划 150px / 600ms | 停在原周 | 翻到下一周 |
| 快速划 360px / 250ms | 翻页 | 翻页 |

改法：

```kotlin
flingBehavior = PagerDefaults.flingBehavior(
    state = pagerState,
    pagerSnapDistance = PagerSnapDistance.atMost(1), // 一次最多翻一页
    snapPositionalThreshold = 0.12f,                 // 约 43dp 就算数
)
```

12% 是手感值：比触摸阈值（约 8dp）高得多，点课程块不会误翻；甩得再快也只走一页，
不会一下跳过五周。日历式的翻页就该"轻推一下就走"，不该像拖动重物。

顺带补了一个抢控制权的隐患：`LaunchedEffect(state.week)` 里做
`animateScrollToPage` 之前先判断 `!pagerState.isScrollInProgress`，
手指还在拖的时候不去和用户拉锯。

## 二、百宝箱 · 今日运气

入口：设置 → 百宝箱 → 今日运气。目前里面只有这一件东西，以后想加别的直接往这个分区里塞。

设计上有三条硬规则：

1. **同一天、同一台设备，分数不变。**
   种子 = 日期 + 本机随机盐（`LuckSaltStore`，SharedPreferences 里一个 Long）。
   所以它不是一个可以一直点、直到点出高分的老虎机 —— 退出去再进来还是这个数，
   凌晨换一个。这才叫"今天的运气"。
2. **好日子稍微多一点，但不能天天好。**
   取值 `u^0.62 × 100`（`u` 是均匀随机）：均值约 62，**60 分以上的概率约 56%**，
   也会真的掉到 30 以下。均匀分布（均值 50）看着就假，人人都 80 分更假。
   这两条都写成了测试（2000 天采样，好日子占比 0.50~0.64，均值 58~66）。
3. **话要像人说的。**
   每个档位三句，按种子选一句。不用"愿你""相信自己""每一天都是礼物"那套，
   也不写"你一定会成功"。比如：

   - 90+「手气有点不正常，抽卡可以冲。」
   - 60-75「够用了。想约人就约，成了算赚，不成也不亏。」
   - 30-44「有点闷。文件记得存，伞记得带。」
   - 30 以下「就……早点睡吧。」

   页面底部明写"它就是个数，别拿它做决定" —— 一个娱乐功能，不该装成占卜。

视觉：270° 刻度环（缺口朝下，数字居中时重心不往上跑），数字从 0 走到结果约 1.1 秒，
比直接蹦出来更像"测"了一次。60 分以下环的颜色转成安静的青灰，扫一眼就知道今天一般。

## 三、隐私说明重写

上一版读起来像生成的：每段都是"我们不做 X，也不做 Y"的三段式，
还有"不存在顺手把数据发到别处的可能"这种自我辩解式的句子。问题是它在**说服**，
而说明书只该**陈述**。

新版只回答四个问题，一段说一件事：

- 存在哪（给了具体路径 `/data/data/com.classflow.timetable/`）
- 什么时候联网（只在点登录时；两个域名写死成白名单）
- 密码怎么办（Keystore 加密、不勾就不落盘、会话怎么清）
- 没做什么（不埋点、不读通讯录、权限只在用到时才申请）

语气按"跟同学解释"来写，允许口语（"跟着一起没""留不下任何副本""没有绕过的打算"），
但每句都得是能被验证的事实。

顺手修掉一个实际存在的问题：这两页原来用 `Scaffold(containerColor = Color.Transparent)`
包内容，`contentColorFor(Transparent)` 取不到值，`LocalContentColor` 会退回黑色 ——
**深色模式下正文近乎不可读**。现在统一用 `LocalGlassPalette` 的
`textPrimary / textSecondary / textTertiary`，跟着主题走。
