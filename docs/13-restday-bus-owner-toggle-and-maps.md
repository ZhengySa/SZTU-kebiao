## 1. 巴士休息日时刻表（补齐）

上一轮只录了工作日表，休息日靠「以小程序为准」兜底。用户发了 8 张休息日截图，
本轮把 8 张表（北区/南区 × 发车/地铁站/教学楼/终点）× 2 个日期类型全部录完。

- `BusData` 结构调整：`tables[方向][站点] = StopTables(workday, restDay)`
- `timetable(direction, stop, workday)` 按日期类型取表，不再返回 null
- `departuresOfDay(..., workday)` 同步加参数
- 页面上「休息日」不再是提示卡，而是完整时刻矩阵；下一班倒计时、已过班次变灰同样生效
- 底部小字标明当前是「工作日表 / 休息日表」

数据自洽性校验（写进单测）：同一条班次上
`发车 07:00 < 地铁站 07:01/07:06 < 教学楼 07:04 < 终点 07:08`，
正好对应小程序标注的 +1 / +4 / +6 / +8.5min。

## 2. 情侣课表 → 「我 / TA」一键切换

用户要求：不要单独的页面、也不要塞在设置里，就要一个按钮，按一下从我的课表切到她的。

- 新增 `core/owner/OwnerView`：全局单例，`StateFlow<String>` 存当前看谁的课表。
  **纯内存**，App 重启回到「我」的课表（避免误以为课表丢了）。
- 今日页与周课表两个 ViewModel 都合并 `ownerView.owner`，用 `GetWeekCoursesUseCase(semester, week, owner)` 取数
  → 一处切换，两页同时变，不会出现「课表是 TA 的、今日是我的」错位。
- UI：`OwnerSwitchPill`（「我 ⇄ TA」小胶囊），放在今日页与周课表页头。
  看自己时是玻璃底，看 TA 时是强调色实底（一眼能看出现在不是自己的课表）。
- 没有 TA 数据时切过去 → `PartnerEmptyCard` 直接给登录导入入口（不用绕设置）。
- **长按胶囊**打开管理：重新导入 TA 的课表 / 清除 TA 的课表。不占主界面空间。
- 导入成功后自动切到 TA 视角（`SztuLoginViewModel` 调 `ownerView.set(PARTNER)`）。
- 删除：`PartnerScreen` 整页、`Routes.PARTNER`、设置页的「关系 / 情侣课表」分组。
  数据层的东西（`owner_key` 归属、独立会话、不存 TA 密码）全部保留不变。

## 已知坑

- 并行编辑同一文件会丢 import，本轮坚持串行改同一文件
- 楼层图的蓝带是「每层底部」，所以切图区间是 `上一带尾 .. 本带尾`，
  第一段起点要跳过 0~1163 的深蓝海报头，否则 1F 会带上整张海报
- **GlassCard 不能用来做对话框**：`glassSurface` 的渐变是
  `[fillTop, palette.glassFill, fillBottom]` 三档，中间那档 `glassFill` 是半透明的，
  所以即使把 fillTop/fillBottom 换成不透明色，卡片中间仍然是透的，正文会糊在弹窗上。
  对话框必须自绘实色容器（本轮 `PartnerManageDialog` 已改）。
- 横版地图（16:9）放进竖屏的 `weight(1f)` 容器会留出大片白边，看着像加载失败；
  改成 `fillMaxWidth().aspectRatio(图片比例)` + 外层 Box 居中，白框就消失了。
