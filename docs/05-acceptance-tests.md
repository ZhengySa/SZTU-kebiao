# 05 · 验收测试清单

> 用途：①第二阶段开发时的 Definition of Done；②第三阶段逐条对照检查的底稿。
> 标记 `[A]` = 可自动化（单测/UI 测试），`[M]` = 需手工在真机验证。

## 一、8 条验收标准的可测用例

## 三、手工回归清单（每次发版前）

- [ ] 首次安装：自动写入 12 节 + 默认学期，进入今日页不崩
- [ ] 未设置学期（清数据后跳过）→ 引导设置，不崩溃
- [ ] 学期开学日在未来 → 今日页显示「学期未开始」，周课表不显示第 0 周
- [ ] 学期已结束 → 显示「学期已结束」+ 切换学期入口
- [ ] 课程名超长（30 字）→ 卡片与课程块省略号，不撑破布局
- [ ] 一门课 5 个时段 → 详情页全部列出，周课表 5 处都有块
- [ ] 一节跨 4 节（第 1-4 节）→ 块高度正确，不覆盖邻近课程
- [ ] 12 节课全排满 → 周课表可完整纵向滚动，节次栏与内容不错位
- [ ] 横屏 → 布局可用（MVP 允许横屏为简单适配）
- [ ] 字体放大到最大（系统无障碍）→ 文字不截断到不可读
- [ ] 通知权限拒绝 → 设置页显示引导，功能不崩
- [ ] 精确闹钟权限关闭 → 提醒仍触发（±10 分钟内），有提示
- [ ] 时区改为 UTC+0 → 课程时间按本地时区换算正确，小组件刷新
- [ ] 小组件添加到桌面时 App 从未启动过 → 不崩溃，显示引导文案

## 四、明确不测（非目标，避免范围蔓延）

- 多设备同步、账号登录、云端备份
- 教务系统真实登录（无官方接口前不做）
- 平板/折叠屏专属布局（MVP 只保证不崩、能用）
- 后台常驻、开机自启保活
